# محرك الإعلانات الذاتي — الخليج (Autonomous Ad Engine v2)

نظام متعدد الوكلاء يُنتج حملات إعلانية لهواتف الجوال ويراجعها وينشرها ويحسّنها لأسواق الخليج (السعودية، الإمارات، الكويت، قطر، البحرين، عُمان)، ويُدار عن بُعد من لوحة تحكم عربية. **يعمل بالكامل بدون متجر** (إدخال المنتجات يدوياً)، والمتجر اختياري تربطه في النهاية.

## التشغيل السريع

```bash
# Linux / macOS
./run.sh
# Windows
run.bat
# أو Docker
docker compose up --build
```

افتح http://127.0.0.1:8000 . مفتاح الدخول يُطبع في سجل الخادم عند أول تشغيل ويُحفظ في `data/.admin_key` (أو ضع `ADMIN_API_KEY` في `.env`).
يتطلب Python 3.11+ . الفيديو يعتمد على ffmpeg (يأتي تلقائياً عبر `imageio-ffmpeg` إن لم يكن مثبتاً).

## ماذا يحدث عند إنشاء حملة

```
منتج (يدوي) ─► 1 الاستراتيجي ─► 2 كاتب النصوص (نص بلهجة كل دولة وسعرها المحلي)
                                   │
                                   ▼
                        4 الامتثال والجودة ◄── يعيد النصوص للكاتب (حتى مرتين) إن وُجدت مخالفة
                                   │ (يحجب الحملة إن بقيت مخالفة حرجة)
                                   ▼
                        3 الإبداع: صور 1:1 و9:16 + فيديو 9:16 لكل دولة (عربي صحيح RTL)
                                   │
                                   ▼
                        4 فحص ثانٍ يشمل الوسائط ─► «بانتظار موافقتك»  ◄── بوابة بشرية، لا صرف قبلها
                                   │ اعتماد
                                   ▼
                        5 النشر (Meta / TikTok) ─► متوقفة أو تعمل
                                   │
                                   ▼ (كل ساعة)
                        6 المحسّن: يجلب الأداء ويطبّق قواعد صريحة بسقف مالي
```

كل خطوة وقرار تُسجَّل في «سجل الوكلاء» داخل الحملة.

## أوضاع التشغيل (الأهم)

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `PLATFORM_MODE=dry_run` | ✅ | محاكاة كاملة: لا يُرسل أي شيء لأي منصة، والأرقام تُعرض بعلامة «محاكاة». للتجربة والتعلّم. |
| `PLATFORM_MODE=live` | | نشر فعلي على Meta/TikTok. **يصرف أموالاً.** |
| `GEMINI_API_KEY` | فارغ | بدونه: قوالب آمنة تستخدم بيانات المنتج فقط. معه: نصوص واستراتيجية ومراجعة ثانية بالذكاء الاصطناعي. |
| `AUTO_APPROVE=false` | ✅ | الاعتماد بشري. لا تفعّله قبل أسابيع من الثقة. |

## الذهاب للنشر الفعلي (Checklist)

1. جهّز حساب Meta Business وصفحة وحساب إعلانات ورمز وصول → `META_ACCESS_TOKEN` و`META_AD_ACCOUNT_ID` و`META_PAGE_ID` (وTikTok بالمثل `TIKTOK_*`).
2. ضع `WHATSAPP_NUMBER` أو `DEFAULT_LANDING_URL` (أو رابط لكل منتج) كوجهة للإعلان.
3. `PLATFORM_MODE=live` ثم أعد التشغيل.
4. أنشئ حملة بميزانية صغيرة (5–10$) واختر **«اعتماد وإنشاء متوقفة»** وافحصها داخل Ads Manager قبل تشغيلها.
5. حدّد سقفك في `MAX_DAILY_BUDGET_USD`.

> ⚠️ **محوّلا Meta وTikTok مكتوبان وفق وثائق الـAPI العامة ولم يُجرَّبا على حساب حقيقي** (لا توجد بيانات اعتماد في بيئة البناء). توقّع احتياج تعديلات صغيرة في أول تشغيل (مثل صلاحيات الرمز أو حقول جديدة تفرضها المنصة). لذلك الاختبار الأول يكون دائماً متوقفاً وبميزانية صغيرة.
>
> ⚠️ روابط `wa.me` كوجهة قد لا تقبلها سياسات Meta كإعلان رابط عادي؛ الأفضل صفحة هبوط بسيطة أو إعداد إعلان «Click-to-WhatsApp» من Ads Manager. و**إن واجهت قيوداً في حسابات الإعلانات أو الدفع** فزر «⬇ حزمة للرفع اليدوي (ZIP)» في أي حملة: تعطيك الصور والفيديو والنصوص جاهزة للصق في Ads Manager.

## ما الذي يضبطه النظام تلقائياً (ولا يمكن تجاوزه)

- **لا ادعاءات كاذبة:** «ضمان» لا يظهر إلا إن كتبتَ نص ضمان للمنتج، «مجاني» لا يظهر إلا إن كان في العرض، عبارات الندرة («آخر القطع») لا تظهر إلا مع مخزون مُتتبَّع حقيقي ومنخفض، والأسعار في النص يجب أن تطابق أسعار المنتج، ولا مقارنات بماركات منافسة.
- **المخزون اختياري:** `تتبّع المخزون` مُعطّل افتراضياً للمنتجات اليدوية (الإعلان يعمل دائماً). فعّله لمنتج فيُحجب الإعلان عند النفاد ويُوقَف تلقائياً إن نفد أثناء التشغيل.
- **قواعد المحسّن (حتمية وقابلة للتدقيق):** إيقاف عند CTR أقل من `MIN_CTR_PCT` بعد 3000 ظهور · خفض الميزانية 25% عند CPC أعلى من `MAX_CPC_USD` · رفعها 20% عند أداء ممتاز بسقف ضعف الميزانية الأصلية ولا يتجاوز `MAX_DAILY_BUDGET_USD` · لا أكثر من تعديل ميزانية كل 24 ساعة · إيقاف عند بلوغ الميزانية الكلية.
- **أسعار الدول:** إن لم تحدد سعراً صريحاً لدولة يُحوَّل السعر الأساسي بأسعار الصرف (عملات الخليج مربوطة بالدولار عدا الدينار الكويتي تقريبي) ويظهر تحذير؛ الأدق تحديد السعر الصريح.

## ربط المتجر (في النهاية، اختياري)

من تبويب «المتجر والإعدادات»: API مخصّص (JSON) أو WooCommerce أو Shopify. بعد المزامنة تُستورد المنتجات والمخزون ويُفعَّل تتبّع المخزون لها. يمكن مزامنة دورية بـ`STORE_SYNC_INTERVAL_MIN`. الاتصال بعناوين داخلية محجوب (حماية SSRF).

## الأمان

- كل مسارات `/api` تتطلب `X-API-Key`. CORS مقيّد. مفاتيح المنصات في `.env` فقط (لا تُخزَّن في قاعدة البيانات ولا تظهر في اللوحة).
- لا تعرّض الخادم للإنترنت بدون HTTPS (reverse proxy مثل Caddy/Nginx). مسارا `/media` و`/uploads` عامّان (بمعرّفات غير قابلة للتخمين) لأن المنصات قد تحتاج جلب الوسائط.
- الصور المرفوعة تُعاد ترميزها (إزالة أي حمولة مخفية) وحدّها 8MB.

## الخط العربي

يُبحث تلقائياً عن خط يدعم العربية (Tahoma/Arial على Windows، DejaVu على Linux). للحصول على مظهر أجمل ضع ملف `.ttf` (مثل Cairo أو Tajawal) في `assets/fonts/` أو اضبط `FONT_PATH`.

## حدود معروفة (بصراحة)

- الفيديو شرائح متحركة (صورة المنتج + المواصفات + السعر) وليس تصويراً سينمائياً؛ لا تعليق صوتي. يمكن إضافة موسيقى عبر `MUSIC_PATH`، ويمكن توصيل مولّد فيديو (مثل Veo) داخل `agents/creative.py`.
- الهدف الإعلاني الحالي «زيارات/نقرات» (Traffic). أهداف المبيعات تحتاج بكسل/كتالوج ومتجراً مرتبطاً.
- المحسّن يقرأ نتائج على مستوى الحملة (لا يختبر A/B بين النصوص بعد).
- قاعدة البيانات SQLite (كافية لمستخدم واحد/فريق صغير). للأحمال الأكبر غيّر `DATABASE_URL` إلى PostgreSQL.
- التزم بسياسات المنصات والأنظمة المحلية للإعلان في كل دولة؛ النظام يساعد لكنه لا يغني عن مراجعتك.
